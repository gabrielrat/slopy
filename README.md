# Ski Slopes in Romania

This is a React application that displays a list of ski slopes in Romania. It also provides a map view of the slopes and can calculate the travel time and distance to each slope from the user's location.

## Installation

1. Clone the repository.
2. Run `npm install` to install the dependencies.
3. Run `npm start` to start the development server.

## Features

* **List View:** Displays a list of ski slopes with their names, travel times, and distances.
* **Map View:** Displays the ski slopes on a Google Map.
* **Geolocation:** Uses the user's location to find nearby slopes.
* **Travel Information:** Calculates the travel time and distance to each slope.

## Technologies Used

* React
* Ant Design
* Google Maps API
